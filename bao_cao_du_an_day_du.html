06 / TARGET CONTRACT

Chọn target và tính sai số bounding box

Perception-control giao tiếp bằng contract nhỏ: tâm box lệch bao nhiêu so với tâm ảnh và box lớn bao nhiêu.

Geometry
box = (x1, y1, x2, y2)
cx = (x1 + x2) / 2
cy = (y1 + y2) / 2
error_x = cx − 208
error_y = cy − 208
area = (x2 − x1) × (y2 − y1)

Scale về coordinate contract 416×416, nên image center là (208,208) dù camera native 640×480.

ROS message

/tracking/error · geometry_msgs/Point

FieldÝ nghĩa
xSai số ngang; dương khi target ở bên phải.
ySai số dọc; dương khi target thấp hơn tâm.
zBbox area trong không gian 416×416, proxy khoảng cách.

Target lock

Click hoặc 1–9

Standby

0 hoặc Space

Gửi ID âm, clear lock và đưa hệ thống về STANDBY.

Distance proxy: area là tín hiệu 2D, không phải depth/3D range. Hysteresis và slew limiter giảm dao động do pose/occlusion.
07 / CONTROL BRAIN

MotionArbiter: state machine và visual servo

Node hợp nhất perception, teleoperation, PX4 telemetry và policy điều khiển. Timer 10 Hz dùng steady clock; mỗi tick chọn đúng một loại setpoint.

STANDBY

Hover/ready; ngang và yaw bằng 0, altitude hold có thể sửa vz.

TRACKING

Nhận error mới, tính visual-servo velocity.

MANUAL

Twist mới nhất có quyền ưu tiên trong 0.5 s.

MANUAL_GOTO

Minimap gửi global-relative position setpoint.

stateDiagram-v2 [*] --> STANDBY STANDBY --> TRACKING: target selected / auto_track STANDBY --> MANUAL: non-zero teleop TRACKING --> MANUAL: non-zero teleop MANUAL --> STANDBY: timeout / stop TRACKING --> STANDBY: target lost > 5 s STANDBY --> MANUAL_GOTO: minimap click TRACKING --> MANUAL_GOTO: minimap click MANUAL_GOTO --> STANDBY: goto reached MANUAL_GOTO --> TRACKING: resume target
Tracking substates

Hành vi bên trong TRACKING

SAFE_ZONE_HOVER, BACKING_SMOOTH, ADVANCING, ADVANCING_CLOSE_IN, BACKING_UP_TO_RECOVER, ADVANCING_TO_TURN_POINT, RECOVERING_YAW_HEADING, SEARCHING_HOLD.

Tick path

One decision, one dispatch

Update telemetry → đọc state dưới lock → tạo vx/vy/vz/yaw_rate → gửi một setpoint MAVLink. ClockType.STEADY_TIME schedule timer; time.monotonic() đo dt.

08 / FLIGHT CONTROL

Từ sai số ảnh đến MAVLink/PX4

Controller tạo high-level setpoint; PX4 chạy estimator, position/velocity loop, attitude/rate loop và actuator mixing.

Velocity frame

vx / vy / vz / yaw rate

vx tiến/lùi, vy trái/phải, vz lên/xuống theo controller convention, yaw rate là tốc độ quay. XY được xoay sang NED theo yaw; vz đổi dấu.

Live Camera HUD

  • Click box để lock; click minimap để GOTO.
  • Banner TRACKING, MANUAL, STANDBY, MANUAL_GOTO.
Priority

MANUAL > automatic reacquisition

Non-zero keyboard command đưa arbiter vào MANUAL; detector nhận /tracking/motion_state và suppress auto re-acquire. Sau 0.5 s không có command, state về STANDBY.

Implementation walkthrough: từ source đến một command

3 · Decision

motion_arbiter_node.py

Nhận error/teleop, chọn state, tính velocity, gửi setpoint và publish motion state/health.

ObservationPolicy
Target inside safe zoneHover, hold altitude.
error_x too largeYaw and limited lateral velocity.
error_y < -deadband_yAdvance toward target.
Area below 6000Close-in, capped at 0.25 m/s.

14 / PRACTICAL GUIDE

First run playbook cho người mới

Một phiên chạy chuẩn gồm chuẩn bị môi trường, khởi động theo thứ tự, quan sát readiness, khóa target và kiểm tra log. Các bước dưới đây bám theo project hiện tại.

Before launch
1. Kiểm tra dependencyROS 2 Humble, Gazebo Harmonic, Python 3.10, PX4 checkout và model yolov8n.pt.
2. Build packagecd ros2_ws && colcon build --symlink-install, sau đó source install/setup.bash.
3. Chọn deviceNormal script kiểm tra CUDA rồi dùng cuda:0; dùng YOLO_DEVICE=cpu khi cần.
4. Chọn worldĐặt WORLD_NAME=person_tracking_no_trees để debug detection đơn giản hơn.

export PX4_DIR=/path/to/PX4-Autopilot
WORLD_NAME=person_tracking_path \
SHOW_HUD=1 LAUNCH_QGC=0 \
./start_stack.sh

Script sẽ báo READY cho Gazebo /clock, PX4 MAVLink, bridge /camera/image_raw, detector /tracking/error và arbiter health.

HEADLESS=1SHOW_HUD=0SIM_REALISM=1TAKEOFF_ALT=3.8
Observe first

Topic checklist

ros2 topic list
ros2 topic hz /camera/image_raw
ros2 topic hz /tracking/error
ros2 topic echo /tracking/motion_state
Operate

Takeoff → lock → track

Nhấn TAB để takeoff. Khi box người xuất hiện, click box hoặc phím 1–9. HUD phải hiện TRACKING PERSON; nếu nhấn W/A/S/D, banner chuyển MANUAL.

Stop safely

Land → Ctrl-C

Nhấn P để land, đợi PX4 disarm rồi nhấn Ctrl-C trong terminal của start_stack.sh. Script cleanup process tree khi thoát.
